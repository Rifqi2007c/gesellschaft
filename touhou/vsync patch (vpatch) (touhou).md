also known as vpatch
download - https://maribelhearn.com/mirror/VsyncPatch.zip

### how to install
- extract the zip file
- copy the these file to touhou games folder:
	- vpatch.exe
	- vpatch.ini
	- vpatch_<th_ver>.dll (according to the game that need to be patch)
		- example: if touhou 6 (th6), copy vpatch_th6.dll to the th6 folder
> choose the latest revision depending on the game if available

### how to use (with thcrap)
thcrap download - https://www.thpatch.net/wiki/Touhou_Patch_Center:Download
after setup thcrap for a game, it will make games.js file in config folder inside thcrap folder

the file should look like something like this:
```
{
  "th07": "C:/Users/rifqi/Downloads/touhou/t7/07\u3000\u6771\u65B9\u5996\u3005\u5922/th6.exe",
  "th07_custom": "C:/Users/rifqi/Downloads/touhou/t7/07\u3000\u6771\u65B9\u5996\u3005\u5922/custom.exe"
}
```

at the line where there is a game executeable file
```
{
  "th07": "C:/Users/rifqi/Downloads/touhou/t7/07\u3000\u6771\u65B9\u5996\u3005\u5922/th6.exe",  <---- here
  "th07_custom": "C:/Users/rifqi/Downloads/touhou/t7/07\u3000\u6771\u65B9\u5996\u3005\u5922/custom.exe"
}
```
- change it to **vpatch.exe**
- try launching the game with the shortcut that were generated by thcrap

### configuring
- edit **vpatch.ini** file to configure
