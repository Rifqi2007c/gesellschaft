- in powershell terminal type
```
$PROFILE
```
it will output:
```
C:\Users\user\Documents\PowerShell\Microsoft.PowerShell_profile.ps1
```
- make the Microsoft.PowerShell_profile.ps1 inside according to the output
	- make PowerShell folder inside Documents if there is non
	- make the .ps1 file
	- or use if there is a way to open text editor app like vscode, nvim, ...
		- exmaple:
			- vscode
				`code $PROFILE`
			- nvim
				`nvim $PROFILE`
		- then save the file
