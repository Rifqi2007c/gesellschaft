local tools
- [[exiftool]] - tool to read, write and edit EXIF meta information
- [[openssl]] - cryptographic library that implements the SSL and TLS protocols
- [[john the ripper]] - hash cracker (CPU intensive)
- [[hashcat]] - hash cracker (GPU intentsive)
- [[steghide]] - embed or extract file inside from another file(cover file)
- [[xxd]] - hex dump viewer, editor and converter
- [[zsteg]] - tool to detect and extract hidden data in PNG and BMP image
- [[tcpdump]] - packet analyzer. capture and display network traffic in real time on Unix-like operating systems. also can be use to read pcap file
