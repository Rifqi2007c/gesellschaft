change cursor focus to use the plugin keybind
https://github.com/nvim-tree/nvim-tree.lua

| bind     | action                            |
| -------- | --------------------------------- |
| a        | make file                         |
| r        | rename file                       |
| d        | delete file                       |
| x then p | x to cut, p to paste it somewhere |
| g?       | open the built-in help menu       |
